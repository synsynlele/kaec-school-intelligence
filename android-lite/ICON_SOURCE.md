# KSI Lite icon source

KSI Lite uses the same canonical KSI product identity as the web application.

- Vector source: `app/icon.svg`
- Runtime raster source for the Android wrapper: `https://www.ksi.name.ng/pwa/icon-512`
- Product mark: `public/ksi-mark.svg`

Do not introduce a separate Android-only logo. The KSI mark is the primary product identity; KAEC-NG remains the endorsed parent brand.
